   - 將兩個 DataFrame 的充電站數量依「縣市」和「行政區」彙整

### 處理步驟制定

1. **新增縣市欄位**
   - 對`df1`新增欄位`縣市`，填入字串「新北市」
   - 對`df2`新增欄位`縣市`，填入字串「臺北市」

2. **欄位命名統一**
   - 重新命名欄位，使兩個 DataFrame 中代表「行政區」的欄位名稱一致
     - 例如，`df1`的`'dis'`改為`'行政區'`
   - 只保留需要的欄位：`縣市`、`行政區`，其他欄位可先忽略

3. **合併資料**
   - 將兩個 DataFrame 合併成一個長型資料表（用縱向合併）
   - 這樣整合後的表格會有`縣市`、`行政區`欄位

4. **計算充電站數量**
   - 針對合併表，依`縣市`和`行政區`進行分組(group by)
   - 以分組結果計算每組的筆數（即充電站數量）

5. **整理輸出格式**
   - 分組結果轉成新表，欄位命名為：「縣市」、「行政區」、「充電站數量」
   - 確保「充電站數量」欄位為整數或適當數字格式

6. **排序**
   - 依「充電站數量」欄位排序
   - 預設由大至小排序（即充電站數量最多的排在最前）

7. **必要檢查**
   - 確認合併後資料沒有遺漏任何資料
   - 確認行政區欄位名稱及資料一致，無多餘空白或異常格式
   - 檢查排序結果是否符合預期

### 總結

- 新增「縣市」欄位
- 統一並選取「行政區」欄位
- 合併兩市資料
- 按「縣市」+「行政區」分組計數
- 結果命名與排序

以上步驟可有效整合新北市與臺北市充電站數據，並依行政區統計數量及排序，符合需求。
==================================
```python
df1['縣市'] = '新北市'
df1 = df1.rename(columns={'dis':'行政區'})
df1_sel = df1[['縣市','行政區']]
df2['縣市'] = '臺北市'
df2_sel = df2[['縣市','行政區']]
result = pd.concat([df1_sel,df2_sel],ignore_index=True)
result = result.groupby(['縣市','行政區'],dropna=False).size().reset_index(name='充電站數量')
result = result.sort_values('充電站數量',ascending=False).reset_index(drop=True)
```
