## 1. 需求統整與資料理解

- 有兩個 DataFrame：`df1` 和 `df2`
- `df1` 來自「112年國道每月營業額.csv」，型態為字串且數字部分有千分位逗號（e.g. '12,142,311'）
- `df2` 來自「113年國道每月營業額.csv」，型態是數字（int 或 float）
- 欄位結構完全相同：第一欄是「區名」，後面為1月到12月的營業額
- 欄位順序不可變，區名欄位要保持不變
- 目標：計算兩年相同區名、相同月份營業額的平均，結果欄位結構不變，保留區名欄位
- 平均值要到小數點第一位（即1位小數）
- `df1` 中數值以字串形式且含逗號，需先轉成純數值型態才能計算

---

## 2. 分析資料結構與型別

- `df1`：
  - 第一欄「區名」為字串
  - 月份欄位為字串，且包含千分位逗號，需要移除逗號並轉整數或浮點數（因為後續計算要平均）

- `df2`：
  - 第一欄「區名」為字串
  - 月份欄位已經是數值型態（int或float）

- 兩個 DataFrame 的「區名」欄位內容應一致，可以視為 key 進行對齊

---

## 3. 計算平均的方法與步驟

1. **資料清理：**
   - 對 `df1`：
     - 將所有月份欄位的字串中的千分位逗號移除
     - 將移除逗號後的字串轉成數值型（整數或浮點數皆可）

2. **資料類型統一：**
   - 確認 `df2` 月份欄位型態為數值（若有浮點數也可接受）

3. **資料對齊＆計算平均：**
   - 兩個 DataFrame 中，對應同一區名與同一月份欄位的值，計算平均值
   - 平均值計算方式：(`df1數值` + `df2數值`) / 2
   - 保持「區名」欄位不動（維持原排序與索引）

4. **格式調整：**
   - 小數點取到「第一位」（四捨五入）
   - 「區名」欄位維持字串
   - 月份欄位輸出為 float 或字串格式都可，但需呈現一位小數

5. **輸出結果**
   - 結果 DataFrame 欄位與排序和原始 DataFrame 相同
   - 區名欄位不變
   - 月份欄位為兩年平均後的小數點第一位數值

## 4. 可能注意事項（雖非必須，但避免錯誤）

- 檢查兩個DataFrame中區名列表是否完全匹配
- 若順序不同，需根據「區名」做合併或索引對齊
- 若有缺失值，應視需求決定是否填補或忽略
- 確定所有月份欄位正確處理，欄位名稱無誤

## 總結步驟

1. 移除 `df1` 月份欄位字串中的逗號並轉數值  
2. 確認 `df2` 月份欄位為數字  
3. 根據「區名」對齊兩個 DataFrame  
4. 逐欄計算平均值（每個月的平均）  
5. 四捨五入平均值到小數點第一位  
6. 保留區名欄位並保持順序  
7. 輸出新 DataFrame 作為結果

如此一來，即可依需求得出兩年營業額的平均結果。
==================================
```python
months = ['1月', '2月', '3月', '4月', '5月', '6月', '7月', '8月', '9月', '10月', '11月', '12月']
for m in months:
    df1[m] = df1[m].str.replace(',', '').astype(float)
df2_months = df2.set_index('區名').loc[df1['區名'], months]
df1_months = df1.set_index('區名')[months]
avg = (df1_months + df2_months) / 2
avg = avg.round(1).reset_index()
result = df1[['區名']].copy()
for m in months:
    result[m] = avg[m]
```
