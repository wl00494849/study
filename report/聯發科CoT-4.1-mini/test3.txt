### 一、需求釐清

1. **目標**：
   - 將兩個 DataFrame（df1、df2）合併，統整券商在兩天的資料。
   - 計算以下指標（針對券商）：
     - 均價（以買進股票的價格加權平均）
     - 總買進股數
     - 總買進成交金額（均價 × 總買進股數）
   - 從合併後的結果中，**排除“沒買入的券商”**（買進股數總和為 0 的券商）
   - 加上該股票的股票代號（由檔名可得，股票代號＝2454）
   - 欄位順序固定為：**券商, 均價, 總買進股數, 總買進成交金額, 股票代號**
   - 均價及總買進成交金額，最後結果保留到小數點第一位

2. **資料結構**：
   - df1 與 df2 擁有相同欄位結構
   - 各 DataFrame 有買進資料分兩組出現在欄位中：
     - 第一組：券商(`券商`)、價格(`價格`)、買進股數(`買進股數`)
     - 第二組：券商(`券商.1`)、價格(`價格.1`)、買進股數(`買進股數.1`)
   - 未來處理時需將這兩組同日買進資料合併（因同一天的買進有兩組資料）
   - 欄位如 `Unnamed: 5`、`賣出股數`等未涉及本次計算，可忽略

3. **資料特性**：
   - 買進股數為整數
   - 均價為浮點數
   - 兩天的資料需合併加總

---

### 二、處理思考與步驟制訂

**步驟 1**：對 df1 和 df2，各自拆分出兩組買進資料集後合併

- 分別從 df1 抽取 `(券商, 價格, 買進股數)` 三欄（組1）

- 從 df1 抽取 `(券商.1, 價格.1, 買進股數.1)` 三欄後重命名對應欄位（組2）

- 將組1與組2合併（垂直合併），產生一張該日的買進資料（"券商", "價格", "買進股數"）

- 同理操作 df2

**步驟 2**：將兩天的買進資料垂直合併在一起，形成整體買進資料表

**步驟 3**：針對合併後的資料，以券商為群組，計算：

- 總買進股數 = 當天所有買進股數加總

- 買進成交總金額 = 各筆買進股數 × 該筆價格，再加總

- 均價 = 買進成交總金額 / 總買進股數

**步驟 4**：過濾「總買進股數 > 0」的券商（排除沒買入的）

**步驟 5**：整理結果欄位

- 新增欄位“股票代號”，設定為 "2454"

- 欄位排列：`券商, 均價, 總買進股數, 總買進成交金額, 股票代號`

- 均價、買進成交總金額取小數點第一位（四捨五入）

### 三、補充釐清

### 四、整體流程小結

2. **兩天買進資料合併**

3. **群組券商計算合計買入股數、成交金額、及加權均價**

5. **加股票代號並調整欄位及格式**

```python
df1_1 = df1[['券商','價格','買進股數']]
df1_2 = df1[['券商.1','價格.1','買進股數.1']].rename(columns={'券商.1':'券商','價格.1':'價格','買進股數.1':'買進股數'})
df1_buy = pd.concat([df1_1, df1_2], ignore_index=True)
df2_1 = df2[['券商','價格','買進股數']]
df2_2 = df2[['券商.1','價格.1','買進股數.1']].rename(columns={'券商.1':'券商','價格.1':'價格','買進股數.1':'買進股數'})
df2_buy = pd.concat([df2_1, df2_2], ignore_index=True)
all_buy = pd.concat([df1_buy, df2_buy], ignore_index=True)
grouped = all_buy.groupby('券商').apply(lambda x: pd.Series({
    '總買進股數': x['買進股數'].sum(),
    '買進成交金額': (x['買進股數']*x['價格']).sum()
}))
grouped = grouped[grouped['總買進股數']>0]
grouped['均價'] = grouped['買進成交金額'] / grouped['總買進股數']
grouped = grouped[['均價','總買進股數','買進成交金額']].round({'均價':1,'買進成交金額':1}).reset_index()
grouped['股票代號'] = '2454'
result = grouped[['券商','均價','總買進股數','買進成交金額','股票代號']]
```
