## 二、資料結構分析與關鍵點

1. **df1與df2的欄有重複結構：**
   - 前半部（序號, 券商, 價格, 買進股數, 賣出股數）代表「買方」資料
   - 後半部（序號.1, 券商.1, 價格.1, 買進股數.1, 賣出股數.1）代表「賣方」資料

2. **目標是針對「買方」資料進行統計，不用理賣方資料**
   - 欄位參考買方：
     - 券商（券商）
     - 價格（價格）
     - 買進股數（買進股數）
   - 需計算「買進成交金額」= 買進股數 * 價格

3. **兩張表要先合併同樣券商的買進資料，再算加權均價**

4. **須去除「買進股數為0」的資料，代表沒有成交不列入**

5. **股票代號來源：檔名中間的數字 "2454"**

## 三、解決問題的步驟規劃

1. **萃取與整理買方資料**
   - 從df1及df2各自選出「券商」、「價格」、「買進股數」三欄。
   - 列中若買進股數為0，先標記（將來過濾）。

2. **合併兩張表買方資料**
   - 將df1與df2的買方資料合併（垂直合併/concat）

3. **過濾掉買進股數為0的紀錄**
   - 留下買進股數 > 0的資料（有交易的買方）

4. **依券商群組化彙總**
   - 計算「總買進股數」：同一券商買進股數加總
   - 計算「總買進成交金額」：價格 * 買進股數，再加總
   - 計算「均價」 = 總買進成交金額 / 總買進股數
   - 均價及成交金額保留一位小數

5. **加入股票代號欄**
   - 股票代號 = "2454"，對每筆數據加入此固定欄位

6. **調整欄位順序輸出**
   - [券商, 均價, 總買進股數, 總買進成交金額, 股票代號]

- 加權均價計算時因可能有浮點誤差，最後四捨五入到小數點一位
- 若沒有券商「買進股數」均為0，則該券商不出現在最終結果中

df_buy_1 = df1.loc[:, ['券商', '價格', '買進股數']].copy()
df_buy_2 = df2.loc[:, ['券商', '價格', '買進股數']].copy()
df_buy = pd.concat([df_buy_1, df_buy_2], ignore_index=True)
df_buy = df_buy[df_buy['買進股數'] > 0].copy()
df_buy['買進成交金額'] = df_buy['價格'] * df_buy['買進股數']
grouped = df_buy.groupby('券商', dropna=False).agg({'買進股數':'sum','買進成交金額':'sum'}).reset_index()
grouped['均價'] = (grouped['買進成交金額'] / grouped['買進股數']).round(1)
grouped['買進成交金額'] = grouped['買進成交金額'].round(1)
grouped.rename(columns={'券商':'卷商', '買進股數':'總買進股數', '買進成交金額':'總買進成交金額'}, inplace=True)
grouped['股票代號'] = "2454"
result = grouped[['卷商', '均價', '總買進股數', '總買進成交金額', '股票代號']]
