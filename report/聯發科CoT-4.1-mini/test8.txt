## 一、需求統整

你有兩個資料框 `df1` 與 `df2`，分別是不同日期的「聯發科2454」股票的券商資料。

需求是：

1. 合併兩天（`df1` 和 `df2`）的券商資料。
2. 求出每個券商的「均價」、「總買進股數」及「總買進成交金額」：
   - 「均價」：買進價格的加權平均價格。
   - 「總買進股數」：兩日買進股數合計。
   - 「總買進成交金額」：均價 × 總買進股數。
3. 去除沒有買入的券商（買進股數合為0的需剔除）。
4. 在結果中加入股票代號「2454」。
5. 欄位順序為：「卷商」、「均價」、「總買進股數」、「總買進成交金額」、「股票代號」。
6. 小數點計算精準到第一位。

## 二、資料結構與重點說明

### 1. 欄位結構

- 表中有成對的左右兩組券商資料。
- 左半邊券商欄位（index 1）: `'券商'`，買進股數欄位（index 3）: `'買進股數'`，買進價格欄位（index 2）: `'價格'`。
- 右半邊券商欄位（index 7）: `'券商.1'`，買進股數欄位（index 9）: `'買進股數.1'`，買進價格欄位（index 8）: `'價格.1'`。

這代表，每一列中包含兩組不同券商買賣資訊。

### 2. 主要關注的是買進相關欄位

- 買進價格與買進股數，用來算買進成交金額（價格 × 股數）
- 若買進股數為0就表示該筆無買入。

## 三、處理步驟規劃

### 1. 整理資料

- 針對 `df1` 和 `df2`，分別將左右兩組券商資料拆成兩個長條格式 (long format) 的資料框，欄位至少包含：

  - 券商名稱
  - 買進價格
  - 買進股數

  如此會有四個欄位：券商、買進價格、買進股數、來源日期（可加日期標記方便追蹤）

- 將左右兩邊拆開後，對每個 DataFrame 進行合併（即日內左右券商合併），可以用縱向拼接（concatenate）的方式。

### 2. 合併兩日資料

- 將 `df1` 與 `df2` 處理後的資料合併縱向拼接，形成一個所有日期、所有券商的資料集。

### 3. 資料過濾與計算

- 過濾掉買進股數為0的資料列，因為沒有買入。

- 依「券商名稱」群組彙總：

  - 計算「總買進股數」= 該券商所有買進股數的加總。
  - 計算「加權買進價格總和」= 買進價格 × 買進股數，加總後用總買進股數除，得到「均價」。
  
- 計算「總買進成交金額」= 「均價」 ×「總買進股數」。

### 4. 篩選與欄位整理

- 去除「總買進股數」為0的券商（這裡剛剛應已排除，但確保最後沒有零買進者）。
- 新增欄位「股票代號」設定為 `"2454"`。
- 欄位排序調整為：券商、均價、總買進股數、總買進成交金額、股票代號
- 均價、買進股數、買進成交金額數值格式化至小數點一位。

## 四、總結

簡單說，透過以下步驟達成：

1. **拆開左右兩邊的券商資訊為長表格格式**（券商、價格、買進股數）
2. **合併兩天的資料成一張長表**
3. **過濾無買進資料（買進股數=0）**
4. **依券商群組計算加權均價＆買進股數合計**
5. **計算買進成交金額=均價*股數**
6. **補上股票代碼＆整理欄位順序及格式**

以上為整體的資料結構分析與處理流程。

```python
df1_left = df1[['券商','價格','買進股數']].rename(columns={'券商':'券商','價格':'價格','買進股數':'買進股數'})
df1_right = df1[['券商.1','價格.1','買進股數.1']].rename(columns={'券商.1':'券商','價格.1':'價格','買進股數.1':'買進股數'})
df1_long = pd.concat([df1_left,df1_right],ignore_index=True)

df2_left = df2[['券商','價格','買進股數']].rename(columns={'券商':'券商','價格':'價格','買進股數':'買進股數'})
df2_right = df2[['券商.1','價格.1','買進股數.1']].rename(columns={'券商.1':'券商','價格.1':'價格','買進股數.1':'買進股數'})
df2_long = pd.concat([df2_left,df2_right],ignore_index=True)

all_data = pd.concat([df1_long,df2_long],ignore_index=True)
all_data = all_data[all_data['買進股數']>0]

grouped = all_data.groupby('券商', as_index=False).apply(lambda x: pd.Series({
    '總買進股數': x['買進股數'].sum(),
    '均價': (x['價格'] * x['買進股數']).sum() / x['買進股數'].sum()
}))
grouped['總買進成交金額'] = grouped['均價'] * grouped['總買進股數']
grouped = grouped[grouped['總買進股數']>0]
grouped['均價'] = grouped['均價'].round(1)
grouped['總買進股數'] = grouped['總買進股數'].round(1)
grouped['總買進成交金額'] = grouped['總買進成交金額'].round(1)
grouped['股票代號'] = '2454'

result = grouped[['券商','均價','總買進股數','總買進成交金額','股票代號']]
```
