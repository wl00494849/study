2. **要計算的內容**：
   - **卷商**：根據 `'券商'` 欄位。
   - **均價**：計算每個卷商的均價，依賴於 `'價格'` 欄位。
   - **總買進股數**：統計每個卷商在兩天內的總買進股數，來自 `'買進股數'` 欄位。
   - **總買進成交金額**：計算結果為「總買進股數」乘以「均價」，即 `總買進股數 * 均價`。

### 處理步驟
1. **數據整理**：
   - 從 `df1` 和 `df2` 兩個 DataFrame 中提取必要的欄位：`'券商'`、`'價格'` 和 `'買進股數'`。
   
2. **合併數據**：
   - 將 `df1` 和 `df2` 依據 `'券商'` 欄位進行合併，使用 `pd.concat` 或其他合併方法。

3. **計算均價與總買進股數**：
   - 對合併後的 DataFrame 使用 `groupby` 方法，依據 `'券商'` 分組。
   - 計算每個卷商的均價（即平均價格），以及總買進股數。

4. **計算總買進成交金額**：
   - 使用計算出的均價和總買進股數來計算總買進成交金額。

5. **整理輸出格式**：
   - 新建一個 DataFrame 將計算出的結果整理成新的欄位順序：`['卷商', '均價', '總買進股數', '總買進成交金額', '股票代號']`。
   - 將預設股票代號（例如 "2454"）加到每一行。

6. **四捨五入**：
   - 將均價和總買進成交金額的結果進行四捨五入到小數點第一位。

7. **輸出結果**：
   - 最終結果可以輸出為新的 DataFrame，此 DataFrame 包含所需的所有計算結果。

這樣依照以上步驟，可以將 `df1` 和 `df2` 中的資料合併、計算統整出所需的報表。

```python
data = pd.concat([df1[['券商', '價格', '買進股數']], df2[['券商', '價格', '買進股數']]])
result = data.groupby('券商').agg({'價格': 'mean', '買進股數': 'sum'}).reset_index()
result['總買進成交金額'] = (result['價格'] * result['買進股數']).round(1)
result['均價'] = result['價格'].round(1)
result['股票代號'] = '2454'
result = result[['券商', '均價', '買進股數', '總買進成交金額', '股票代號']]
```
