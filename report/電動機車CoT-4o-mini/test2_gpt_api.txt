1. **提取所需資料**:

   - 從 `df2` 中提取 `行政區` 和 `編號`（因為每個編號表示一個充電站）。

- 最終結果的 DataFrame 應該包含以下欄位：

  - `行政區`

df1_count = df1.groupby('dis')['number'].count().reset_index()

df1_count['縣市'] = '新北市'

df2_count = df2.groupby('行政區')['編號'].count().reset_index()

result = pd.concat([df1_count, df2_count], ignore_index=True)
